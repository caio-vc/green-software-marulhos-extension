# Por que desenvolvi

O dashboard de locações do Green Software reúne reservas de hotel e condomínio. Para consultar quantas unidades pertenciam a cada grupo, quantas estavam na casa ou tinham saída prevista, era necessário identificar as reservas e contar manualmente.

Com dezenas de registros, essa conferência tomava tempo e precisava ser repetida quando os dados mudavam. A extensão foi criada para fazer essa separação e facilitar a consulta no sistema já utilizado, sem alterar as reservas.

O projeto usa HTML, CSS e JavaScript. O arquivo `scan.js` lê as tabelas e o `popup.js` cuida dos filtros, das contagens e da interface. As regras de uso estão no README.
